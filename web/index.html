作品目录

  1. CodeFlow

    基于 AST 静态分析的代码审查工具，覆盖 TypeScript、Python 与 Go。目前主要用于我们组的 monorepo，每天约跑 400 次。规则以插件形式扩展，社区贡献了 11 条。

    langTypeScript ver0.14.2 stars2,412 push2026-09-28

  2. SwiftDeploy

    把 Docker 镜像推到 Cloudflare Workers / Fly.io / Vercel 三个平台的单一 CLI。没有 YAML，没有 plugin 系统。核心 800 行，够用时就这样。

    langGo ver1.2.0 stars1,834 push2026-08-14

  3. PixelUI

    给内部产品用的 React 组件库，32 个组件。刻意不做主题系统，只保留一份暗色变量表。所有交互组件走 WAI-ARIA Authoring Practices，测试通过 axe-core。

    langTypeScript ver3.1.4 stars3,627 push2026-10-01

  4. LogLens

    本地运行的结构化日志浏览器。读取 JSON Lines 文件，提供 grep、时间线、字段透视，不需要先把日志发到云上。适合单机调试和隐私敏感的场景。

    langRust ver0.9.0-rc.2 stars962 push2026-06-22

  5. ConfigKit

    Python SDK，把环境变量、远程配置（Consul / etcd）与本地文件收敛成同一份 schema。冷启动 40ms 以内，支持 watch 与 graceful reload。

    langPython ver2.0.1 stars721 push2026-09-11

  6. AuthGuard

    Express / Fastify 中间件。OAuth 2.1、Passkey、Session，一份 API。JWT 只在无状态场景使用，其余情况优先 session。附带速率限制与 refresh token 轮转。

    langTypeScript ver1.6.3 stars1,286 push2026-07-30

维护札记

我不相信一个人能同时维护六个高活跃仓库。这份列表里，PixelUI 与 CodeFlow 是每天真的在用的，SwiftDeploy 每季度会更新一次，LogLens、ConfigKit 和 AuthGuard 处于稳定运行、少量维护的状态：修 bug、合 PR、每年做一次依赖升级，不加新功能。

Issue 我 24 小时内看，PR 优先看测试覆盖。如果我不打算接一个功能，会在两周内说明理由而不是让它在 backlog 里躺着。这条规矩来自我自己维护者时期最讨厌的体验。

依赖方面我一向保守。Node 生态只信 pnpm、vitest 与 esbuild；Python 用 uv + pyright；Go 只用标准库，除非标准库确实缺东西。选依赖的判断标准不是流行度，是维护者是否公开回应 issue。

关于命名，我偏执地认为名字要能读出来。SwiftDeploy 曾经叫 sd，直到我发现同事在会议里说"es-dee 那个东西"完全听不懂，就改了。
